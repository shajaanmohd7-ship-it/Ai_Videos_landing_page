# Sociallyconnect AI Video Works - Portfolio Landing Page

A modern, high-converting, responsive AI video production portfolio showcase created for **Sociallyconnect**, connected directly with Google Drive video assets.

## ✨ Features

- **50 Curated Videos**: Automatically parsed and structured from Google Drive folder `1BFs6zc9Vvdx-_Lsy_rB221ImoEe_6Gec`.
- **Cinema Lightbox Modal Player**: Seamless inline video playback using Google Drive embed frames with fast loading and autoplay support.
- **Smart Category Filtering**:
  - Commercials & Ads (18 Videos)
  - Finance & Corporate (12 Videos)
  - Education & Global (11 Videos)
  - Narrative & Drama (6 Videos)
  - AI & Showreels (3 Videos)
- **Live Instant Search**: Real-time filtering across titles, descriptions, and file names.
- **Next / Previous Navigation**: Browse effortlessly through all 50 videos inside the modal lightbox with keyboard arrow key support.
- **Dynamic Google Drive Thumbnails**: Automatically loads preview covers directly from Google Drive CDN with elegant fallbacks.
- **Modern Dark UI**: Designed with Tailwind CSS, Lucide icons, glassmorphism, and responsive layouts for mobile, tablet, and desktop.

## 🚀 How to Run Locally

Run the threaded streaming server:
```bash
python server.py
```
Then visit `http://localhost:5173` (or on mobile: `http://<your-ip>:5173`).

## 🌐 Deploy Online (Free in 2 Minutes)
- **GitHub Pages**: Push this repo to GitHub, go to `Settings > Pages`, and select `main` branch.
- **Vercel / Netlify**: Drag and drop this folder directly to Vercel or Netlify for an instant live URL.
